# Code of Conduct

## Our standard

Participants in this project are expected to be respectful, constructive, and
focused on improving the software and its documentation. Harassment,
personal attacks, discrimination, and deliberate disruption are not welcome.

## Maintainer response

Project maintainers may edit or remove contributions that violate this code,
the repository license, or applicable law. Reports should be made privately
through the contact method listed in the repository owner's GitHub profile.
