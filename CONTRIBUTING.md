# Contributing to NPCMicro13M

Suggestions, bug fixes, documentation improvements, and deployment
integrations are welcome.

Before opening a pull request:

1. Read `README.md` and the included license.
2. Keep model behavior changes reproducible by documenting the checkpoint,
   device, runtime settings, and representative inputs used.
3. Do not commit private transcripts, credentials, local paths, or generated
   fine-tuning outputs.
4. Run the lightweight checks described in the README.
5. Explain behavior changes with representative before/after examples.

Contributions are subject to the repository's included license unless a
separate written agreement says otherwise.
